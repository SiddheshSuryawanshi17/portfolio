# Siddhesh Suryawanshi · Portfolio

My personal site. Built with React, Vite, GSAP, Lenis and Three.js.

## Change what the site says
Everything (bio, projects, experience, skills, links) is in **`src/data/content.js`**.

## Add images
See **`public/images/README.md`**.

## Update the résumé
Replace `public/resume.pdf` (the source lives in `Resume/`).

## Run it on your computer
```bash
npm install
npm run dev      # opens at http://localhost:5173
```

## Build
```bash
npm run build    # output goes to dist/
```
